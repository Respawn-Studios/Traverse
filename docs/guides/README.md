# Traverse guides

Start with the [feature guide](features.md) to find your way around panes,
archives, servers, editing and storage tools. It follows current development;
the notes beside your download tell you what's in that particular build.

Want to improve a guide or show off a useful workflow? A short example with
disposable files is a great contribution. Show the everyday path first and
save the advanced choices for readers who want them.

Developers should use [Contributing](../../CONTRIBUTING.md) and
[local setup](../engineering/DEVELOPMENT_SETUP.md). Screenshots and
tutorial recordings follow the [media guide](../media/README.md).
For questions, ideas and repository access, see
[community entry points](../engineering/COMMUNITY_AND_DISTRIBUTION.md#community-channels).
