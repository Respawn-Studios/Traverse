# Branding assets

`traverse-banner.png` is promotional artwork for the repository and project site.
It follows Traverse's blue folder and compass icon; it is not an application
screenshot. The runtime icon remains in the app's existing resource owner.

`traverse-icon.png` is the actual 1024px app icon, extracted without alteration
from the `ic10` representation in `App/MacExplorer/Resources/AppIcon.icns`.
Use it for the README and project pages; the app still uses its canonical ICNS.
The PNG SHA-256 is
`70c6817ab2a799068b34020aaf166d84560881e0c8447c0f3e3640dcdc930cff`;
the source ICNS SHA-256 is
`951bc63adb873687d41be7d16a93bb16cf39158accad42e70498858f8e575057`.
The [trademark policy](../../../TRADEMARKS.md) covers the name and icon.

The banner is AI-generated artwork we're using while Traverse finds its feet.
We'd love to collaborate with an artist and replace it with original,
artist-created work that gives the project its own character. If that sounds
like your kind of project, say hello in
[Discord](https://discord.gg/UdKp2uQBQy) or email
[hello@respawn-studios.com](mailto:hello@respawn-studios.com).

The existing app icon is staying. `manifest.json` records where each asset came
from, along with its dimensions and checksum. Please include useful alt text
when using the artwork, and show the real app with disposable data in product
screenshots and tutorials.
