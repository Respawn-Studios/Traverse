# Private names

PrivateNames.swift is the app owner; PrivateNamesEditor.swift, PrivateNamesLibrary.swift and PrivateNamesManagement.swift present names/access/Forget. FileMemory is the storage/identity authority. Saved labels are independent of AI and file-content indexing.

These are folders within the same App module, not additional packages. Consult App/README.md and docs/engineering/README.md from the repository root.
